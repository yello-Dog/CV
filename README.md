## 个人简介

具备一定的机器人与嵌入式工程实践经验，曾独立推进较完整的轮足机器人项目，对方案设计、硬件搭建、软件开发、整机调试、故障定位与持续迭代的完整流程具有较为实际的认识。在项目中接触并处理过电机、传感器、通信、实时任务调度及软硬件协同等问题，能够从系统现象出发，耐心分析并定位故障。

重视实际成果，希望参与的工作最终能够落实为可运行的系统、可复现的实验或可验证的阶段性研究成果。

## 专业基础与实践能力

### 机器人与嵌入式系统

- 对机器人项目从设计到落地的工程流程具有实际认识。
- 具备 MCU 开发经验，对电机、传感器、通信、实时任务调度及软硬件协同有一定实践基础。
- 设计过单片机核心板、模拟信号发生器和简易示波器等电路，对 PCB 设计及基础模拟电路具有一定实践经验。

### 控制理论

- 系统学习过经典控制理论、信号与系统及现代控制理论。
- 较为详细地学习和推导过 LQR、线性 MPC、卡尔曼滤波、iLQR 和 DDP 等基于模型的控制与轨迹优化方法。
- 关注算法的模型假设、数学结构、工程实现条件，以及在真实机器人系统中的适用边界。

### 数学与物理基础

- 系统学习过线性代数、微积分和优化等课程。
- 接触过泛函分析等进阶数学内容，能够耐心阅读包含数学符号与推导的论文和技术材料。

### 机器人软件

- 接触过 ROS 1 和 ROS 2，具备基本认识。
- 目前尚未在完整项目中使用 ROS 进行工程实践，但具备快速重新上手并投入开发的基础。
